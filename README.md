# Five websites, one model

Five concept websites invented, designed and built by Claude Fable 5.2 from a single prompt.

Live: https://akashmakesdesigns.github.io/fable-sites/

| Site | What it is |
|---|---|
| Counterpunch | Type foundry with a cursor-reactive variable-font headline |
| Pith | Sparkling citrus brand whose page recolours per flavour |
| Nadir Lodge | Dark-sky lodge with scroll-driven star trails and a real moon phase |
| Oriel 38 | Mechanical watch, exploded in 3D as you scroll (Three.js) |
| Tacta 75 | Mechanical keyboard, seven layers exploded in 3D (Three.js) |

All brands are fictional. Every visual is drawn in code.

## Run locally

```bash
npm install
npm run dev:1   # dev:1 to dev:5, ports 5181 to 5185
npm run build   # writes the static sites to docs/
```
